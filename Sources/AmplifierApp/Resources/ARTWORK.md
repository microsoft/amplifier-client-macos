# Crystal avatar artwork

User-selected, image-generated crystal sculptures: Relay, Accord, d20, Crest,
Meter and a Clippy tribute. Clear and Dark are independently generated and
approved material variants. Blue/cyan light channels and neutral glass highlights
support the native palette transform. No personal images or machine data are
included. Asset hashes, sizes and frame counts are in GENERATED-ARTWORK.json.

Each `<shape>[-dark].png` is a registered transparent pose atlas: four columns of
320 × 320 cells. Relay has six poses, Accord/Clippy eight, the others sixteen.
`<shape>[-dark]-working.png` is a transparent animated PNG where present.
Native interpolation supplies Relay/Meter working loops directly from the poses.
See docs/avatar-animation.md for state choreography and playback constraints.

MenuBarIcon.png and MenuBarIcon@2x.png remain the official Amplifier menu-bar
template assets from microsoft/amplifier assets/branding/icons. The @2x asset
matches Git blob 1a798aae8238c9906406be2cca3aee89b1646b16.
