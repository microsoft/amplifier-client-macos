# Roadmap

## Initial public preview

Ship the native menu-bar client, quick composer, notifications and optional Tempo
companion with browser-approved host connection, signed/notarized installation
and signed updates. Use the official Amplifier icon throughout the app.

Preparation tracks the [release-readiness checklist](release-readiness.md).
A universal build or a successful source test does not replace real-device
acceptance. The preview should state its limits plainly.

## Next product slices

1. Add a workspace window using the shared web client, with intentional sign-in,
   reliable link routing, one window/connection owner and a bounded native bridge.
2. Improve native journeys where useful: keyboard navigation, accessibility,
   file handling, quick invocation and system integrations.
3. Offer separately authorized device capabilities, including an enrolled
   existing browser and canonical desktop fallback. Preserve local human control.
4. Consider deeper native workspace views after the shared-web workspace is
   qualified; do not duplicate shared conversation or provider semantics.

These are directions, not commitments to a release date. Safari web-app discovery,
voice and full saved-message removal remain candidates. Removing saved replies
must preserve durable suppression of repeated callbacks.
